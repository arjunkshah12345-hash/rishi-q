# Data Statement (RISHI-Q)

## Purpose

Support blinded structural annotation of philosophical passages for a computational study of alleged quantum-structural analogues.

## Data types

1. **Synthetic / physics-reference passages** — authored for instrument validation; redistributable with the MIT-licensed code.
2. **Bibliographic pointers** — metadata for copyrighted scholarly translations (e.g., Olivelle 1998); full text not redistributed here.
3. **Public-domain candidates** — to be ingested only after license verification (Perseus, Gutenberg, GRETIL, etc.).
4. **Annotations** — model/human labels with evidence spans; human labels absent until external validation.

## Sensitive / ethical notes

Texts are historical-philosophical. No personal data. Avoid sensational claims that could misrepresent religious traditions.

## Redistribution rule

Access ≠ redistribution permission. When rights are unclear, release `passage_id`, hashes, transformation code, and bibliographic pointers only.

## Splits

- `development` — exploratory
- `confirmatory_locked` — empty until preregistration
- Never mix splits in analysis artifacts
