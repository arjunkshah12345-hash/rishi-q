# Limitations

1. Confirmatory analysis is locked pending preregistration.
2. Human validation has not occurred (`REQUIRES_EXTERNAL_HUMAN_VALIDATION`).
3. Local annotator is heuristic; Kaggle multi-model replication pending.
4. Development corpus is initially synthetic + bibliographic pointers; full 500–800 licensed passages not yet acquired.
5. Perfect source blinding is impossible for famous passages.
6. Dating of ancient texts is uncertain; use intervals.
7. Embedding contamination risk if used as primary (they are not).
8. Expert Sanskrit/physics review outstanding.
9. Literature freeze still needs verified DOI fill for fast-moving NLP papers.
